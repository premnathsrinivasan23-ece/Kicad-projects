# Inverter Circuit

KiCad files and circuit simulation for an inverter circuit.
⚡ Inverter Circuit Simulation
📌 Project Overview

This project demonstrates the design and simulation of an inverter circuit using KiCad. An inverter is an electronic circuit that converts a DC supply into an AC output.

The circuit uses switching components to periodically change the direction of current through the load, thereby producing an alternating output waveform.

🎯 Objective

The main objective of this project is:

To understand the working principle of an inverter.
To design the inverter circuit using KiCad.
To simulate the circuit and observe the input and output waveforms.
To study the conversion of DC power into AC power.
⚙️ Working Principle

The inverter receives a DC input voltage from a power source.

The switching circuit operates alternately, causing the output voltage to change polarity periodically. This creates an alternating waveform at the output.

In simple terms:

DC Input
   ↓
Switching Circuit
   ↓
Alternating Switching Action
   ↓
AC Output
