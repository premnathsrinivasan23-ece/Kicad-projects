# LED Simulation using KiCad 9

## Project Description

This project demonstrates a simple LED circuit simulation using KiCad 9 SPICE Simulator.

## Circuit Components

- DC Voltage Source: 5V
- Resistor: 1kΩ
- LED
- Ground (GND)

## Circuit Connection

5V DC Source → 1kΩ Resistor → LED → Ground

## Simulation Type

DC Operating Point Analysis

## Simulation Results

- Supply Voltage: 5V
- LED Current: Approximately 4.3 mA
- The LED was successfully forward biased.
- The circuit simulation was completed successfully.

## Software Used

- KiCad 9
- KiCad SPICE Simulator

## Learning Outcomes

- Created a schematic in KiCad
- Added and connected electronic components
- Performed Electrical Rules Check (ERC)
- Assigned SPICE simulation models
- Configured component pin assignments
- Performed DC Operating Point Analysis
- Analyzed voltage and current results
